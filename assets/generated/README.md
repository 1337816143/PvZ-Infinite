# 生成资产归档说明

本目录保存本轮对话中生成的概念图资产信息。

## 1. 资产范围

- `concept-poster-01`：总体游戏概念海报；
- `design-summary-02`：持久成长、玩家主体与复生机制方案图。

## 2. 归档内容

- 原始生成文件名；
- 图像尺寸和字节数；
- SHA-256；
- 图像生成ID；
- 原始生成说明；
- 当前会话中的可下载原图链接记录；
- 后续正式上传到仓库时的核验依据。

## 3. 完整性原则

- 图片中的文字、布局与细节属于概念可视化，不自动视为最终UI或正式美术规范；
- 设计事实以主设计文档和逐轮讨论记录为准；
- 不应用重新生成的相似图片覆盖原图记录；
- 后续若增加二次编辑版本，必须使用新文件名并在清单中记录父版本；
- 原始文件应按照 `manifest.md` 中的SHA-256校验，避免误传或覆盖。

## 4. 当前技术说明

本轮所用GitHub连接接口仅支持直接写入UTF-8文本，不能把会话中的本地二进制PNG路径直接作为仓库文件上传。因此当前仓库先完整保存两张原图的生成元数据、校验值和会话文件名；原图本身仍保存在本次ChatGPT会话产物中。此限制不得被误写为“原图已经进入GitHub”。
