# HTML总档案与GitHub Pages规范

## 1. 目标

项目同时维护两种访问能力：

1. **无损单文件档案**：`PvZ-Infinite-Archive.html`，用于离线查看、历史快照、全文搜索和原文件恢复；
2. **GitHub Pages入口**：`index.html`，部署在 `main / (root)`，直接进入最新总档案。

当前Pages配置正确，不需要切换为Actions部署或`/docs`目录。

## 2. 无损要求

除生成档案自身和Git内部目录外，构建器必须扫描仓库文件并保存：

- 相对路径；
- 原始字节；
- Base64内容；
- 字节数；
- MIME类型；
- SHA-256；
- 内容分类。

阅读视图、预览视图和本地编辑不能修改快照中的原始字节。每个文件必须支持无损导出。

## 3. 支持格式

### 文本与代码

- Markdown、TXT、JSON、YAML、TOML、INI、CSV、XML；
- HTML、CSS、JavaScript、TypeScript、Python、Shell、PowerShell、SQL；
- 常见配置、许可证和说明文件。

### 图片

- PNG、JPG/JPEG、WEBP、GIF、SVG、AVIF等浏览器可显示格式。

### 音频

- MP3、WAV、OGG、M4A及浏览器可播放格式；
- 页面内显示播放器，不单独跳转。

### 视频

- MP4、WEBM、OGV及浏览器可播放格式；
- 页面内播放，支持全屏和控制条。

### 文档

- PDF页面内嵌查看；
- 其他办公文档至少提供元数据和无损导出，后续按需增加解析器。

### 3D模型

优先支持：

- `.glb`：推荐交付格式，单文件、最稳定；
- `.gltf`：支持关联`.bin`、纹理和其他相对资源。

交互要求：

- 模型直接显示在当前文件阅读区域；
- 鼠标/触摸旋转；
- 滚轮/手势缩放；
- 平移和视角复位；
- 自动旋转可开关；
- 不强制打开单独页面。

当前采用Google `<model-viewer>`，生产页面固定版本，避免CDN升级造成不可控变化。其`camera-controls`用于鼠标和触控交互。GLTF外部资源在单文件档案中应改写为内嵌Data URI；找不到依赖时必须显示明确错误和缺失路径。

后续可扩展OBJ、FBX、USDZ，但这些格式不得阻塞GLB/GLTF基础能力。

## 4. 安全规则

- 仓库中的HTML和SVG默认以源代码展示，不能直接执行未知脚本。
- PDF、视频、音频和3D预览使用浏览器原生或受控组件。
- 外部脚本必须固定版本并记录来源。
- 任何用户上传的可执行HTML不得自动获得父页面权限。
- 本地编辑仅保存到浏览器LocalStorage，不能自动写回GitHub。

## 5. 页面结构

- 农业科技感深色视觉；
- 项目名称、版本、生成时间和快照哈希；
- 文件分类侧栏；
- 文件名与全文搜索；
- 阅读、原文、本地编辑三个视图；
- 复制、导出原文件、导出本地修改；
- 弃用想法醒目标识；
- 项目规则独立分类；
- 图片、媒体、PDF和3D模型采用相应预览器。

## 6. Pages入口

当前设置：

- Source：Deploy from a branch
- Branch：`main`
- Folder：`/(root)`

根目录必须存在`index.html`。入口可以轻量跳转到`PvZ-Infinite-Archive.html`，但必须提供手动链接和无JavaScript回退。

## 7. 自动构建

`.github/workflows/update-integrated-archive.yml`负责：

1. 检出main；
2. 应用当前增量迁移脚本；
3. 运行HTML构建器；
4. 生成或更新`index.html`；
5. 提交文档与HTML；
6. 防止机器人提交再次触发循环。

构建输出必须进入提交，否则Pages仍会显示旧版本。

## 8. 大型项目阶段

随着游戏项目启动，图片、音频、视频和模型会使单HTML快速增大。

### 当前阶段

继续无损嵌入全部仓库内容，便于完整归档。

### 触发扩展架构的条件

出现任一情况时必须评估：

- HTML接近80MB；
- 单次浏览器解析明显卡顿；
- 仓库接近GitHub单文件限制；
- 3D、视频或音频资产数量快速增长。

### 扩展方案

- Pages在线浏览器按需读取原始资产；
- 无损快照按版本发布到GitHub Releases或外部对象存储；
- 大文件使用Git LFS或资产仓库；
- 主HTML仍索引全部文件、许可、哈希和下载地址；
- 不得静默跳过大文件。

- [ ] Markdown样式正确；

- [ ] 音频和视频可播放；
- [ ] PDF可内嵌；
- [ ] GLB可旋转和缩放；
- [ ] GLTF依赖可解析或给出明确缺失信息；
- [ ] 原文件导出哈希一致；
- [ ] 生成文件数量与预期相符；
- [ ] 输出自身没有递归嵌入。
