## C. 当前核心共识核对

- [ ] 永久农场不结束，但农业日有阶段和黎明结算。
- [ ] 存活的永久资产不机械清零。
- [ ] 临时变异和夜间肉鸽卡牌进入白天时失效。
- [ ] 永久变异基因可保存、DIY、复刻和高门槛交易。
- [ ] 同种植物有自然形态差异。
- [ ] 移动战斗型特定变异植物可成为独立个体。
- [ ] 当前编队验证上限为1名角色加4株移动战斗型植物。
- [ ] 接管植物时，角色和其他植物默认转为跟随该植物。
- [ ] 自由人物、载具和适配单位支持多视角目标。
- [ ] 普通防御以自动化为主，大型设备采用简化区域命令。
- [ ] 合作迁入不能复制原世界全部资产。
- [ ] PvPvE不永久删除完整家园。
- [ ] 被否定方案必须原位标为弃用。
