## 优先级

发生冲突时按以下顺序处理：

1. 用户当前明确要求；
2. `AGENTS.md`；
3. 当前主游戏构思；
4. 本目录详细规则；
5. 专题设计和历史建议。

用户当前要求可以修改既有规则，但必须把修改写入仓库并保留旧规则的变更记录，不能只在聊天中临时覆盖。
