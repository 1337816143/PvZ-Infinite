# 2026-08-01：主游戏设计文档专业化与默认展示修正

## 本轮问题

用户指出：虽然仓库和HTML已经积累了大量设计内容，但进入Pages后没有直观看到一份专业、完整、方便浏览的游戏主设计。主设计必须集中涵盖所有已经讨论的已确认项、弃用项、待定项，并明确完整游戏方案和系统边界。

## 诊断

原 `docs/design/00-master-game-concept.md` 已包含大量系统细节，但仍存在以下结构问题：

1. 更接近完整概念基线，而非专业Master GDD；
2. 缺少统一状态图例；
3. 已确认、待验证、待定和弃用内容分散；
4. 缺少集中产品边界、非目标和系统依赖；
5. 首个原型缺少明确验收条件；
6. HTML默认打开 `AGENTS.md`，造成主设计不明显；
7. Markdown阅读器不支持专业状态表格和Master GDD章节目录。

## 已执行

### 主GDD

在原主设计文件内增量升级，没有新建另一套竞争性总架构：

- 标题升级为“主游戏设计文档（Master GDD）”；
- 版本升级为Concept v0.4.1；
- 明确其为唯一权威游戏方案和边界基线；
- 新增文档控制、状态图例和快速导航；
- 新增一页式游戏全貌、玩家幻想、核心体验承诺、三层循环和模式架构；
- 新增系统状态总览；
- 新增产品边界、本作明确是/不是、当前阶段不做；
- 集中登记待定、待验证和尚未讨论项；
- 新增已确认设计决策总表；
- 新增弃用想法与名称总表；
- 新增系统边界、非目标与依赖关系；
- 扩展首个原型范围、非目标和十项验收条件；
- 澄清临时变异与永久变异的生命周期边界。

### HTML与Pages

- GitHub Pages继续使用 `main / (root)`；
- `index.html`继续进入单文件总档案；
- 总档案默认打开Master GDD；
- 新增“主游戏设计”和“AI规则”快捷按钮；
- Master GDD自动生成章节目录；
- 标题生成稳定锚点；
- Markdown阅读器增加表格渲染；
- 继续支持文本、图片、音视频、PDF和GLB/GLTF预览。

同步更新：

- 设计决策登记表；

## 质量修正

首次自动构建中发现Markdown阅读分支出现 `};else if` 前端语法错误。已修正迁移脚本并重新构建，最终HTML中的条件分支和默认打开逻辑通过源代码核验。

## 保持不变

本轮没有重构或推翻：

- 永久农场世界；
- 美国农场场景；
- 农业日循环；
- 360°塔防；
- 选择性重置；
- 自由角色与自动植物；
- 植物个体和模块化变异；
- 1人+4移动植物验证框架；
- 火种计划；
- 单机、邻居合作和PvPvE；
- 离线双护罩；
- 交易系统阶段化方向。

## 当前状态

`docs/design/00-master-game-concept.md` 是唯一权威Master GDD。专题文档用于展开细节，完整对话用于追溯语境，AI规则用于维护工作流，均不得形成另一套互相冲突的总设计。
