# 2026-08-01：持久成长、自由主体与复活机制讨论纪要

## 用户提出的异议与确认

1. 认可昼夜循环：
   - 清晨收获；
   - 白天建设与长期成长；
   - 黄昏预警；
   - 夜晚多方向袭击；
   - Boss或特殊事件；
   - 黎明结算。

2. 不接受每晚重置植物变异和炮塔。

3. 用户倾向：
   - 角色死亡时损失角色身体上的局内加成；
   - 农场资产只有被摧毁时才损失；
   - 肉鸽卡牌和短期天气可以重置；
   - 植物变异应低概率、高随机、多样化，并跨夜保留；
   - 炮塔跨夜保留；
   - 台风、雨雪、酸雨等长期天气可持续数日。

4. 玩家存在方式不是三选一，而是：
   - 轻量策略指挥；
   - 可自由移动的主体角色；
   - 植物和基础防御自动攻击；
   - 重点指挥大型无人农机、无人机、机器人和远征单位；
   - 玩家主体操作简便、自动攻击、跟随鼠标移动、点击交互；
   - 玩家会死亡、掉落资源；
   - 死亡后启动受《瑞克和莫蒂》Operation Phoenix启发的原创复活系统。

## 本轮形成的设计结论

### 1. 黎明是结算，不是全场清空

黎明只重置夜间卡牌、短期命令和短期天气。存活的植物、炮塔、建筑和稳定变异继续存在。

### 2. 用自然约束替代机械重置

长期平衡依靠：

- 土地、水、电、弹药、燃料和维修容量；
- 农场实力越强，世界威胁响应越复杂；
- 强力变异需要环境和维护；
- 敌人产生针对性克制；
- 扩张增加防线长度和运输负担；
- 资产遭受真实战损；
- 稀有资产可通过基因库或档案进行高成本、不完整恢复。

### 3. 肉鸽卡牌与持久变异分离

肉鸽卡牌本身在黎明失效，但卡牌可以诱发真正的植物突变、设施改造或事件结果。只要对象在战斗中幸存，该结果就保留。

### 4. 风险契约改名建议

“风险契约”指玩家主动接受额外困难以换取更高奖励的可选条件。当前更推荐称为“风险委托”。

### 5. 玩家主体操作方向

- 植物、炮塔、宠物和基础机器人自动工作；
- 角色跟随鼠标方向移动；
- 点击用于交互、建设、维修、拾取和操作设施；
- 大型无人农机和远征单位使用区域级简化命令；
- 提供战略视图，但不把游戏变成高强度微操RTS；
- 同时保留WASD作为可选移动方式，避免长时间鼠标跟随造成疲劳。

### 6. 原创复活系统

暂定推荐名“火种计划”。

核心规则：

- 角色意识定期备份；
- 死亡后写入培养体或替代身体；
- 原身体、装备和背包留在死亡地点；
- 临时身体强化和未同步状态会损失；
- 复活消耗时间、电力、生物材料和培养体；
- 农场在复活期间继续自动战斗；
- 合作玩家可以保护复生设施和回收尸体；
- 复生设施失效时，意识进入黑匣子等待恢复。

## 当前待讨论问题

1. 玩家角色是固定人物、自定义人物，还是可更换的多个身体/职业？
2. 鼠标跟随移动是否应当是默认模式，还是与WASD并列？
3. 自动攻击的目标选择如何兼顾简单与可控？
4. 大型农机远征是实时在大地图运行，还是采用派遣与局部实时接管混合？
5. “火种计划”的技术来源是人类科技、外星逆向工程，还是植物生物科技？
6. 死亡尸体是否可能被感染、绑架或克隆成敌对单位？
7. 独特变异植物被摧毁后，恢复应保留多少特征？

## 下一轮建议优先事项

优先确定玩家角色的操作与死亡闭环，因为它会直接影响：

- 镜头；
- UI；
- 建造与拾取交互；
- 联机复活；
- 载具控制；
- 战斗节奏；
- 首个原型范围。
