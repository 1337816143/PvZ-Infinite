# 美国农场场景调研与地图建议

更新时间：2026-08-01

## 1. 调研目标

本调研回答三个问题：

1. “房子在路边，右侧是广袤农田”是否符合美国农场？
2. 玩家房屋按邻居、对门或街区排列是否真实？
3. 怎样在真实性与塔防可玩性之间找到最佳布局？

## 2. 核心结论

### 2.1 房屋靠近道路、农田包围建筑群：合理

美国传统农场通常不是单独一栋房子直接贴在农田边，而是一个“farmstead（农场宅地/农场建筑群）”：农舍靠近公共道路或私人车道，周围或后方聚集谷仓、机棚、粮仓、筒仓、牛棚、围栏和作业场，再由农田、牧场、林带与沟渠包围。

因此，“房子在路边，右侧是大农田”可以作为一个镜头构图，但不应成为所有地图都严格相同的固定规则。更真实的方式是：

- 农舍位于道路附近；
- 私家碎石车道连接道路与院落；
- 生产建筑位于住宅后侧或侧后方；
- 农田从两侧与后方展开；
- 牛棚和牧场与住宅保持一定距离；
- 北侧或西北侧设置L形/U形防风林；
- 低洼处可有排水沟、池塘或湿地；
- 电线、围栏和田间机耕道强化美国乡村识别度。

美国国家公园管理局的乡村景观资料也常将农舍描述为靠近道路，并与附属建筑和田块形成紧密组合；美国农业部资料则将农场宅地、农场道路、私人农场通道纳入典型农业土地系统。

### 2.2 “街区式密集住宅”不适合典型大农场

在美国中西部和大平原农业区，农场宅地通常较分散，建筑群沿县道、乡村道路或地块边界分布。道路常与规则地块网格相互配合，农场之间往往隔着大片田地。

因此，像城市住宅区那样每隔几十米一栋房、道路两边密集“对门”的布局，会削弱大农场感。

### 2.3 邻居和对门并非不可能，但需要换一种解释

游戏可以采用以下三种更可信的多人布局：

#### A. 同一路段相邻农场（推荐用于2人）

两座农场沿同一条县道排列，中间相隔一块田、一道林带或一个公共机械场。为了游戏节奏，可以把现实中的数百米距离压缩为几十至一百多米。

优点：

- 最符合“邻居”概念；
- 能形成左右互援；
- 道路天然成为共同防线和敌人通道；
- 各玩家仍保持独立农场边界。

#### B. 乡村十字路口合作聚落（推荐用于3至4人）

四个农场分别位于十字路口不同象限，共享粮仓、加油站、维修站、供水塔或合作社。

优点：

- “对门”变得合理；
- 四面受敌与多人分区天然成立；
- 中央路口可作为公共防御核心；
- 适合构建强烈的美国乡村视觉符号。

#### C. 家族农场/农业合作社院落（推荐用于紧凑合作地图）

多栋住宅和生产建筑共用一条私人道路，解释为家族成员、雇员住宅或合作社。玩家不是传统城市邻居，而是同一农业经营体的不同成员。

优点：

- 可以让房屋靠得更近；
- 易于共享电网、仓库、牛棚和维修设施；
- 非常适合早期小型合作原型。

## 3. 推荐的地区原型

### 3.1 首选：虚构的美国中西部—大平原过渡区

不要直接复制某个真实州，而是组合以下特征：

- 爱荷华、伊利诺伊、印第安纳式大面积玉米/大豆田；
- 内布拉斯加、堪萨斯、北达科他式笔直县道和开阔地平线；
- 大平原防风林、粮仓、筒仓和大型机械棚；
- 少量池塘、溪流、树林和起伏地形，为玩法提供变化。

这样既有观众熟悉的“美国农场”视觉，又能自由设计天气、地形和怪物路线。

### 3.2 不建议首版直接采用的地区

- 加州大型灌溉农场：农业视觉鲜明，但缺少经典红谷仓、玉米地和风雪氛围；
- 德州超大牧场：适合牛群与荒野，但种植塔防场景密度较低；
- 阿巴拉契亚山地小农场：地形丰富，但不符合“广袤平整农田”印象；
- 新英格兰石墙小农场：视觉独特，但田块更碎、小路更曲折。

这些地区可作为后续生物群系，而不是第一张主地图。

## 4. 防风林为什么重要

美国农业部自然资源保护局将farmstead windbreak定义为设置在农舍、建筑和作业区附近、与主要不利风向近似垂直的树木/灌木带。其作用包括降低风速、减少建筑能耗、控制积雪位置和保护生活环境。

北达科他州林业资料指出，典型农场防风林常呈L形或U形，多排树木包围乡村住宅或农场院落。

### 对游戏的价值

防风林不应只做装饰，它可以成为：

- 阻挡视线与远程攻击的地形；
- 减速虫群与僵尸的软墙；
- 木材、果实和野生动物资源点；
- 火灾、虫害和外星污染的风险区；
- 冬季控制积雪的位置；
- 玩家可种植、修剪和改造的长期防御设施。

## 5. 推荐的单人初始农场布局

```text
                    北 / 冬季主风向

       多排防风林 ┌────────────────────┐
                  │  工具棚  谷仓  筒仓 │
                  │                    │
   西侧农田       │  牛棚——牧场         │      东侧主农田
                  │       作业院        │
                  │    农舍  菜园       │
                  └──────┬─────────────┘
                         │碎石车道
=========================县道=========================
                  邮箱 / 路牌 / 电线杆

       南侧可扩建区：果园、池塘、温室、风机或太阳能设施
```

这一布局比“道路左边只有房子、右边只有农田”更真实，也更适合从四面组织敌人。

## 6. 推荐的多人地图结构

### 6.1 两人：同路邻居

```text
 [玩家A农场]──田块/林带──[公共机械场]──田块/林带──[玩家B农场]
 ========================县道============================
```

敌人可沿道路快速推进，也可从两侧田野包抄。玩家需要决定是各守各家，还是把公共机械场改造成共同堡垒。

### 6.2 四人：十字路口合作街区

```text
        [玩家A]     │     [玩家B]
                    │
        农田────────十字路口────────农田
                    │
        [玩家C]     │     [玩家D]
```

中央公共设施建议包括：

- 农业合作社；
- 加油站/维修站；
- 水塔；
- 粮食电梯或铁路装卸点；
- 警报塔；
- 公共变电站。

这比城市式住宅街区更符合农场世界，同时保留“邻居/对门”玩法。

### 6.3 自由对抗：县域地图

玩家农场彼此相距较远，中间由以下地点连接：

- 县道和碎石路；
- 废弃小镇；
- 粮仓与铁路支线；
- 河桥；
- 军事检查站；
- 外星坠毁点；
- 虫巢和传送门；
- 中立农场与贸易站。

玩家攻击应集中在运输队、临时前哨、资源点和战斗实例，不直接永久摧毁对方主家园。

## 7. 场景中的标志性物件清单

为了让玩家一眼识别“美国农场”，首张地图建议优先出现：

- 木结构或白色农舍；
- 红色谷仓或金属机棚；
- 圆柱形粮仓、筒仓或粮食电梯；
- 碎石车道、路边邮箱和木质电线杆；
- 玉米、大豆或小麦田；
- 牛棚、围栏、饮水槽和奶牛；
- 拖拉机、联合收割机、皮卡和拖车；
- L形/U形防风林；
- 风车、泵、水塔或小型池塘；
- 县道路牌、铁路道口或远处小镇天际线。

## 8. 对“房子右侧是农田”的最终建议

可以保留这个构图作为玩家第一次进入游戏时的视觉记忆：镜头从道路一侧进入，左前方是农舍和邮箱，右侧是延伸至地平线的玉米地，后方可见红谷仓、筒仓和奶牛。

但地图系统不应锁死方向。每座农场应根据道路、风向、水源和地块随机生成朝向，确保：

- 农舍靠近道路；
- 主田块占据最大连续空间；
- 防风林位于主要风向一侧；
- 牛棚、仓储和机械区与住宅形成合理距离；
- 至少保留两条敌人可利用的自然通道；
- 多人加入时可以无缝扩展道路和地块。
