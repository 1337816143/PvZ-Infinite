## 一、场景：建议采用“虚构的美国中西部—大平原过渡县”

你的“房子在路边，右侧是广袤农田”是合理的，但需要稍微扩充。

典型场景应当是：

```text
                    北侧防风林
       ┌────────────────────────┐
       │  谷仓  机棚  筒仓  发电设施 │
西侧田 │                        │ 东侧主农田
       │  牛棚—牧场    作业院     │
       │       农舍—菜园          │
       └─────────┬──────────────┘
                 │碎石车道
=================县道=================
          邮箱、路牌、电线杆
```

美国农场通常以“farmstead”形式存在，即农舍、谷仓、机棚、筒仓、牛棚、作业场和私人车道组成建筑群，田地从两侧和后方延伸。农舍常靠近道路，生产建筑则在侧后方。大平原地区还常见L形或U形多排防风林，用于阻风、控制积雪和保护农场建筑。

### 多人房屋怎样排列

不建议采用城市式“街区”，因为那会削弱大农场感。建议分为三种布局。

**两名玩家：同路邻居**

两座独立农场沿同一条县道排列，中间隔着农田、树林或公共机械场。现实距离可以适当压缩。

```text
玩家A农场 —— 农田 —— 公共机械场 —— 农田 —— 玩家B农场
=======================县道=======================
```

**三至四名玩家：乡村十字路口合作聚落**

```text
       玩家A     │     玩家B
                 │
农田──────────合作社──────────农田
                 │
       玩家C     │     玩家D
```

这样“邻居”和“对门”都成立。中央可以设置：

- 农业合作社；
- 加油站和维修站；
- 水塔；
- 公共变电站；
- 粮食电梯或铁路装卸点；
- 公共警报塔。

**紧凑合作地图：家族农场**

多栋房屋共用私人车道、牛棚、仓库和机械区。世界观解释为家族成员、农场雇员或农业合作社，而不是普通城市邻居。

美国中西部和大平原广泛存在规则地块、笔直道路和分散农场建筑群，因此“县道邻居”和“十字路口农场”比密集住宅街区更可信。

## 二、3D还是2.5D：建议采用“完整3D，2.5D式操作”

我的明确建议是：

> **完整3D场景、单位和物理表现，主镜头采用可旋转、可缩放的斜俯视策略视角。**

也就是技术上是3D，操作感和信息表达接近2.5D。

这样能同时满足：

- 四面八方来敌；
- 飞碟在空中盘旋和降落；
- 虫族地下钻出；
- 机甲和车辆行驶；
- 农田、道路和建筑自由扩建；
- 塔防单位数量较多时仍然看得清楚。

不建议首版加入自由第三人称射击。否则项目会迅速从塔防扩张为射击、驾驶、建造、RTS、开放世界混合游戏，开发规模会失控。

可以设计局部特写：

- 飞碟牵引光束锁定奶牛时镜头拉近；
- 巨型虫族从玉米地破土时轻微震屏；
- 农场机甲启动时播放短暂特写；
- Boss撞穿谷仓时切换电影化角度。

但战斗控制始终保持策略视角。

## 三、“无限”应当是永久世界，而不是一局永远打下去

真正永不结算的一局会导致：

- 后期数值无限膨胀；
- 玩家不敢下线；
- 联机玩家难以同步进度；
- 新玩家无法加入；
- 每次上线都在继续处理上次没结束的残局。

建议采用双层循环。

### 长期层：永久农场

永久保存：

- 房屋、道路和土地；
- 谷仓、牛棚、能源设施；
- 科技、蓝图和角色；
- 宠物、机器人和载具；
- 收藏、剧情和区域声望。

### 短期层：一个昼夜或灾变周期

每次约20—35分钟：

```text
清晨收获
→ 白天建设
→ 黄昏预警
→ 夜间多方向袭击
→ Boss或特殊事件
→ 黎明结算
```

肉鸽卡牌、临时植物变异、临时炮塔、天气效果和本轮风险契约在结算后重置。

所以“无限”的真正含义是：

> 农场永远可以继续发展，但每次战斗都有明确的开始、高潮、结算和喘息期。

## 四、全方位来敌不能等于随机乱刷怪

地图可以没有传统五条固定路线，但必须存在“软路线”。

### 硬路线

- 县道和碎石路；
- 农场大门；
- 桥梁；
- 地下隧道；
- 外星传送门；
- 虫巢出口。

这些路线移动速度快，敌人数量集中。

### 软路线

- 玉米行和收割后的空地；
- 排水沟；
- 围栏缺口；
- 防风林通道；
- 牧场；
- 被Boss撞出的新路径。

玩家可以通过围栏、植物、沟渠、燃烧地带和机械改变软路线，但不能永久堵死地图。

这会形成一种比传统固定路线更自由、又比纯开放寻路更有策略性的战场。

## 五、猫狗拾取系统值得保留，但两者要有本质差别

### 小狗

- 移动速度快；
- 拾取范围大；
- 可以拖回大型资源箱；
- 能沿玩家指定路线巡逻；
- 会吸引部分敌人注意；
- 后期可装备背包和轻型护甲。

### 小猫

- 可以穿过狭窄缝隙；
- 可以跳上矮墙、屋顶和谷仓平台；
- 更擅长拾取稀有、小型资源；
- 不容易吸引敌人；
- 能发现外星信号、地下虫穴和隐藏物品。

宠物不建议永久死亡。生命值耗尽后应当逃回农舍、宠物窝或兽医站，短时间无法继续工作。

局外成长可以是：

- 初始购买价格降低；
- 初始拾取半径提高；
- 数量上限提高；
- 解锁装备槽；
- 解锁初始技能。

局内仍然需要消耗资源进行雇用、升级、复活和路线配置。

## 六、外星人、虫族和僵尸不要简单组成同一阵营

建议建立三角敌对生态。

### 僵尸

- 数量最多；
- 行为相对直接；
- 喜欢沿道路、门口和破损围栏推进；
- 承担基础塔防压力。

### 虫族

- 从地下虫穴和传送门出现；
- 速度快，擅长绕后；
- 会污染农田；
- 可以孵化和扩散巢穴；
- 部分虫族能寄生尸体。

### 外星人

- 使用飞碟、无人机和牵引光束；
- 干扰电网；
- 绑架奶牛；
- 捕获植物、僵尸和虫族做实验；
- 在地图上建立临时传送设施。

三方可以互相攻击：

- 虫族吃掉或寄生僵尸；
- 僵尸攻击虫巢中的活体；
- 外星人捕获双方；
- 玩家可以把僵尸群引向虫族传送门；
- 飞碟牵引Boss时，玩家可以趁机输出。

这样世界会产生真正的动态战场，而不是三套外观不同、实质都只攻击玩家的敌人。

## 七、奶牛应该成为核心系统，不只是彩蛋

奶牛可以承担五种功能：

1. **农业生产**：牛奶、肥料、皮革替代材料、沼气原料。
2. **外星预警**：飞碟出现前，牛群躁动、叫声变化或聚集。
3. **保护目标**：飞碟会锁定稀有奶牛，玩家必须切断牵引光束。
4. **救援任务**：被绑架后可追踪飞碟或进入外星设施夺回。
5. **变异系统**：部分奶牛被外星改造后，可能产生特殊资源，也可能吸引更强敌人。

甚至可以出现肉鸽卡牌：

- 奶牛受到牵引时，为附近设施补充电力；
- 牛铃变成声波防御设备；
- 沼气设施产量翻倍，但更容易爆炸；
- 保护整夜未受伤的奶牛，黎明获得稀有卡牌；
- 允许外星人带走一头牛，换取追踪其母舰的坐标。

## 八、机器人和载具采用RTS指令，不先做复杂驾驶

首版建议：

- 拖拉机：清障、拖拽、碾压低级敌人；
- 农用无人机：侦察、播种、喷洒和投弹；
- 农场机器人：维修、搬运、装填；
- 皮卡：运输资源和快速救援；
- 联合收割机：收割作物，也可改造成重型近战单位；
- 农用机甲：高耗能紧急战斗单位。

玩家通过点击目标、划定路线和设置工作区域进行控制。

之后可以加入“临时接管驾驶”，但不应成为首版核心。

## 九、联机切换中存在一个必须解决的漏洞

你提出：

> 新玩家进入邻居模式时只获得一栋房屋，但原来的资源和属性全部叠加在这栋房屋上。

这个方案会产生严重问题：

- 多栋高级建筑被压缩为一栋超级建筑；
- 玩家可能反复切换模式复制资源；
- 主机和新玩家资产关系不清；
- 强玩家加入后可能直接使合作难度和经济失衡。

建议改为“迁入系统”。

玩家带入：

- 长期科技；
- 已解锁蓝图；
- 角色和宠物；
- 有额度限制的物资；
- 原家园形成的“家园价值评分”。

系统根据评分提供：

- 初始迁入补给；
- 建筑蓝图；
- 建设加速；
- 一定数量的预制模块。

但原来的房屋和设施不会直接压缩或复制。

## 十、离线护罩很有辨识度，但高能模式必须修改

蓝色半透明科技护罩是一个很好的视觉符号，可以成为游戏的重要标志。

### 低能休眠护罩

- 所有玩家离线后无限持续；
- 保护永久家园；
- 服务器保存基地快照并停止完整战斗模拟；
- 敌人在表现层被推开、分解或改道；
- 不产生无限掉落。

### 高能自主防御

- 消耗农场电网中的储能；
- 离线计算植物、炮塔和机器人的防御表现；
- 有最大结算时长；
- 奖励逐渐递减；
- Boss只会被击退或留下追踪任务，不能离线无限刷Boss；
- 能量耗尽后自动切换为低能模式。

不建议允许玩家直接充值购买无限防御能源。它会迅速变成明显的付费战力和离线资源优势。更合适的付费内容是基地主题、宠物外观、植物皮肤、动画和非战力便利内容。

## 十一、自由模式最好做成“战斗实例”，而不是永久摧毁家园

玩家的永久农场应当保留。

进入自由模式后，玩家携带有限资源，在区域中建立战地基地或前哨站。

可以损失：

- 本局建造的设施；
- 一部分带入资源；
- 本局采集资源；
- 运输车辆；
- 未撤离的战利品。

永久保留：

- 科技；
- 蓝图；
- 角色；
- 收藏；
- 永久农场建筑；
- 核心宠物与载具解锁。

大本营被摧毁后触发撤离倒计时和结算，而不是删除长期资产。

胜利者也不能无限掠夺，必须受到：

- 战利品撤离容量；
- 资源带出上限；
- 连胜悬赏；
- 匹配强度；
- 世界敌人关注度。

## 十二、知识产权必须从第一天考虑

美国版权局明确说明，游戏的抽象创意和玩法方法本身通常不受版权保护，但图像、美术、文字和其他具体表达可能受到保护。EA现行用户协议也保留其游戏内容及相关知识产权，并限制未经授权的复制、修改和分发；EA社区经理对《植物大战僵尸》非商业同人游戏的公开答复也是建议申请许可。

因此建议：
