## 当前功能与边界

纯二维世界坐标与斜俯视投影；旋转、缩放、平移、点选、测试柱放置/移除、人物标记移动与绕障。适应工具栏行列与安全留白，HOME适配视野；L形占位体的内部墙面隐藏，基于占地/高度的遮挡淡化。仍不是任意建筑或多层世界的通用遮挡方案。

存档有校验、验证临时写入、有效旧备份与启动自动恢复；暂停/失焦清理操作并保存。兼容旧实验快照，损坏全部副本时保留文件并报告。校验用于检测意外损坏，不是反作弊；不保证断电、磁盘故障或卸载后永不丢档。

FX压力档仅绘制128/512个移动标记，不进行敌人AI、寻路或战斗，不改变世界存档。缓存与遥测有上限；文字复用排版、排序深度预计算。帧间隔使用实际单调时钟，不能把引擎delta限制解释成稳定帧率。短压力试验不是长时间发热/功耗结论。

本目录不替代根目录主GDD。长期游戏的持久农场、360°防守、昼夜与成长不被删改；这里没有正式角色、美术、经济、关卡和战斗。本次安卓目标是2.5D斜俯视和可旋转观察，不承担完整3D或第一/第三人称，也不加入联网玩法。

## 打开工程与操作

用 **Godot 4.5.2 Standard（非.NET）** 导入 `spikes/01-rotatable-25d/project.godot`；仅安装APK试玩不需要引擎。英文和几何图形都是占位。

MOVE点地面移动；PLACE/ERASE放置或移除自建测试柱；TURN L/R按住旋转；HOME回正并适配视野；-/+缩放；SAVE/LOAD保存/读取实验状态。**FX 0/128/512是绘制压力档，LOAD才是读档。** GRID切换网格。桌面支持WASD、Q/E、右键旋转和滚轮。

单指轻点执行模式、拖动平移，双指旋转/缩放/平移；真实物理多指手感未测试。Android横屏为当前导出方向；桌面竖长窗口仅是布局回归，不代表手机竖屏玩法已完成。部分Android屏幕比例采用黑边适配，逻辑视口仍为1280×720。
