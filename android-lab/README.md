# 安卓 2.5D 技术验证区

版本：Lab v0.1.0。创建日期：2026-09-05。

**这是赛前独立技术练习，不是正式参赛游戏，不得作为赛期内开发成果申报。**

本目录不替代根目录主 GDD。长期游戏仍以持久农场、360°防守、昼夜与成长为核心；这里暂时只有几何地块、遮挡柱和移动标记，没有正式角色、美术、关卡、战斗或经济系统。用户已明确本次安卓版本采用 2.5D 斜俯视与可旋转观察，不承担完整 3D 或第一/第三人称。

## 打开工程

使用 **Godot 4.5.2 Standard（非 .NET）** 导入 `spikes/01-rotatable-25d/project.godot`，按 F6/F5 运行。画面英文仅为技术占位，不代表正式游戏语言。

- 桌面：左键点选；MOVE 模式点地面移动，PLACE 放置测试柱，ERASE 移除自己放的柱。
- Q/E 或屏幕旋转按钮持续转动；鼠标右键拖动也可旋转。滚轮或 +/- 缩放；HOME 回正。
- WASD 或屏幕方向键移动。方向按当前画面映射，不随镜头产生反向操作。
- 移动端：单指轻点执行当前模式，单指拖动平移；双指旋转/缩放/平移。多指操作结束不会触发放置。
- SAVE/LOAD 只保存本技术练习的地块与位置；不涉及任何真实游戏存档。

## 目录

- `spikes/01-rotatable-25d/`：独立可导出的 Godot 工程。
- `ci/`：固定版本下载、自动测试、安卓构建及包检查脚本。
- `docs/`：验收、参赛边界、素材来源和后续接手说明。
- `logs/`：真实准备记录；**不是 TapTap 已发布开发日志**。

唯一需要放在本目录外的新增文件是 `.github/workflows/android-lab.yml`，因为 GitHub 只从固定的 `.github/workflows/` 目录发现工作流。没有替换 Pages 入口、旧档案或主游戏工程。
