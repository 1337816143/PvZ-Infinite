## 打开工程与操作

使用 **Godot 4.5.2 Standard（非 .NET）** 导入 `spikes/01-rotatable-25d/project.godot`。只试玩 APK 不需要安装 Godot。画面英文和几何图形仅为技术占位。

- 桌面：左键点选；MOVE 点地面移动，PLACE 放置测试柱，ERASE 移除自己放的柱。
- Q/E 或屏幕旋转按钮持续转动；鼠标右键拖动旋转；滚轮或 +/- 缩放；HOME 回正。
- WASD 或屏幕方向键移动，方向按当前画面映射。
- 移动端：单指轻点执行当前模式，单指拖动平移；双指旋转/缩放/平移。真实多指手感仍待手机验证，自动化覆盖的是输入路由和模拟器注入事件。
- SAVE/LOAD 只操作本实验地块与位置。启动自动恢复；放置/移除、周期以及暂停时保存。
