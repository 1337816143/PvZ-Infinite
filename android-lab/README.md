## 打开工程

使用 **Godot 4.5.2 Standard（非 .NET）** 导入 `spikes/01-rotatable-25d/project.godot`，按 F6/F5 运行。只试玩 APK 不需要安装 Godot。画面英文仅为技术占位，不代表正式游戏语言。

- 桌面：左键点选；MOVE 模式点地面移动，PLACE 放置测试柱，ERASE 移除自己放的柱。
- Q/E 或屏幕旋转按钮持续转动；鼠标右键拖动也可旋转。滚轮或 +/- 缩放；HOME 回正。
- WASD 或屏幕方向键移动。方向按当前画面映射，不随镜头产生反向操作。
- 移动端：单指轻点执行当前模式，单指拖动平移；双指旋转/缩放/平移。多指操作结束不会触发放置。这些真实触摸体验仍待手机测试，自动化只验证输入路由。
- SAVE/LOAD 只保存本技术练习的地块与位置；不涉及任何真实游戏存档。
