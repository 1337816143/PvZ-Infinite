# 手机试验操作说明

适用：Lab v0.1.0 / 构建 4 / 独立安卓调试包。

**这是一份待执行测试单；这里有操作说明，不代表真实手机或 TapPlay 已经通过。**

## 安装与进入

把 `farmlab-debug.apk` 传到安卓手机并安装，应用名为 Farm Camera Lab。只试玩不需要 Godot、Git 或开发环境。按系统提示仅对所用安装来源授予必要权限，不需要关闭全局安全防护。此调试包不是正式上架包，也不应直接投稿。

清单声明最低 SDK 24、目标 SDK 35；实际兼容性须以设备测试为准。

## 控件对照

| 控件 | 中文含义 | 试验内容 |
|---|---|---|
| MOVE | 移动模式 | 轻点空地，标记按地面路径绕过柱体 |
| PLACE | 放置模式 | 在空地放置金色柱体，不能与角色或已有柱体重叠 |
| ERASE | 移除模式 | 只移除自己放置的金色柱体，不能删除固定灰色柱体 |
| TURN L / TURN R | 左转 / 右转 | 持续按住，水平转动观察方向 |
| HOME | 回正 | 恢复默认角度、缩放和中心 |
| - / + | 缩小 / 放大 | 调整观察范围 |
| SAVE / LOAD | 保存 / 读取 | 只保存与读取这份独立试验的世界状态 |
| UP / DOWN / LEFT / RIGHT | 屏幕方向移动 | 镜头旋转后，按键方向仍应符合屏幕方向 |

地图上单指拖动平移；双指可旋转、缩放和平移。多指松开后不应意外放置新柱体。控件区不是地图手势区。

## 建议一次完成的检查

先 MOVE 进入空地，再 PLACE 放两个金色柱体，按住 TURN L 转一圈；检查柱体不漂移。旋转后再点击空地，确认选中的是手指所在格。切 ERASE 验证只移除金色柱体。然后在 PLACE 模式进行双指缩放，松手不应多出柱体。最后 SAVE，修改一些位置或柱体，LOAD 应恢复之前状态。

跨启动试验：先 SAVE，退出并重新进入后手动点 LOAD；当前版本不自动把旧实验存档载入启动场景。切后台时有实验自动保存，不能据此推断所有系统终止情形已经验证。

遇到建筑遮挡角色时观察柱体是否变淡。当前算法只验证单格柱体和单层地面，不代表复杂建筑和多层地形已经解决。
