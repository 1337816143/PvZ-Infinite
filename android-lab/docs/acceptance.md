# 第一步验收边界

## 自动化计划（只有成功运行才算通过）

1. Godot 真正导入所有 GDScript，无解析或运行错误。
2. 72 个方向 × 3 个缩放 × 121 格 × 5 个格内测试点：正反投影与点选。
3. 旋转后的屏幕方向移动映射；旋转缩放手势锚点不漂移。
4. 非法放置、角色重叠、碰撞防穿透、绕障路径。
5. 本地保存/恢复；损坏或不同 schema 拒绝且不改现有世界。
6. 引擎实际渲染 45/135/225/315 度截图；不是概念图或独立网页渲染。
7. 实际调用同一输入路由验证轻点放置、多指操作不误放置。
8. 真正导出 APK，检查签名、包名、ARMv7 与 ARM64 库，以及无 INTERNET 权限。

## 必须在安卓和 TapPlay 内另测

- 真实手机启动、屏幕安全区、双指手势、帧率和发热。
- 切后台/返回、系统中断、连续退出/重进后的本地存储。
- TapPlay 启动与平台稳定性检测，不以普通 APK 安装代替。
- 独立上架包名与长期签名、商店图标、展示材料、实际投稿，均不属于本调试包完成范围。

## 已知限制

- 单层平面、有限 11×11 网格、单格测试柱；没有真实 3D 地形。
- 物体按脚底深度绘制，遮挡时柱体淡化，角色位置环仍可见。此策略需要真机检查；不是任意大建筑、跨层结构或大体积单位的完整遮挡算法。
- 几何占位与英文调试界面不是最终美术/语言。
- 自动截图和输入路由测试不能证明物理触摸、GPU 兼容、长期稳定性或性能已经达标。
- 点击寻路是测试工具，不代表正式游戏最终操作方案；存档也不能迁入正式游戏。
- 临时调试签名每次可能不同；不要将其视为正式 TapTap 上架签名。
