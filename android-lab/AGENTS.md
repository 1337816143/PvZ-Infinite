# 本目录协作规则

本目录是 2026-09-05 起创建的赛前技术验证，不是正式参赛工程。用户授权新内容独立存放，不能覆盖旧设计或将旧游戏改名后参赛。

1. 本阶段只测试纯二维逻辑 + 斜俯视投影、旋转、点选、遮挡、触控、存储与安卓构建；不引入 3D 场景、联网功能或正式内容。
2. 根目录历史设计保留。长期 GDD 中的 3D/联机目标不适用于这个练习的交付范围，且不得因此被永久删除。
3. 所有新增项目文件放这里；GitHub 工作流入口必须放根目录 `.github/workflows/`，业务脚本仍放 `ci/`。
4. 测试命令和真实证据见 README、docs/acceptance.md 和 logs。构建成功不等于安卓启动，不等于 TapPlay 通过。
5. 使用占位几何，不打包容器字体，不复制任何第三方游戏资产。AI 辅助代码如实说明，正式项目需另外维护资产披露表。
6. 不提交 keystore、密码、身份证、令牌或本地 .godot 缓存。不强制推送或改写历史。
7. 新功能必须有验证，未运行的测试标待验证。准备记录与 TapTap 公开开发日志分开，不能伪造发布时间。
8. 本目录的 Lab 版本独立于长期 Concept 版本；不要运行历史迁移脚本来重构无关主稿。
