# PvZ Infinite / 植物大战僵尸：无限（暂定名）

> 一个以美国农场为舞台、支持持续建设、360°防御、肉鸽成长、合作街区与开放对抗的长期型塔防/RTS游戏构想。

## 项目状态

当前阶段：**概念设计与可行性论证**。

本仓库用于长期保存：

- 游戏愿景、世界观与核心玩法；
- 每轮讨论的纪要、结论与待决问题；
- 美国农场、乡村道路、建筑布局等场景调研；
- 单机、合作、自由对抗模式的系统设计；
- 植物、僵尸、外星人、虫族、动物、机器人和载具体系；
- 原型路线、技术架构、美术方向与测试结果；
- 后续生成的概念图、原型图和其他产物。

## 当前核心定位

本作不是把传统《植物大战僵尸》简单改成四面出怪，而是构建一个完整的“**持久农场世界 + 360°肉鸽塔防 + 轻度RTS + 自由角色 + 合作/对抗联机**”体系。

当前确认的技术、视觉与循环方向：

- 底层采用完整3D场景；
- 主视角采用可旋转、可缩放的斜俯视策略镜头，获得2.5D式清晰度；
- 玩家拥有可自由移动、会受伤和死亡的主体角色；
- 植物、炮塔、宠物和基础机器人主要自动工作；
- 策略指挥重点用于大型无人农机、无人机、机器人和远征单位；
- 农场可持续扩建，战斗通过昼夜、天气、季节、灾变和远征形成阶段性节奏；
- 黎明是结算和修整节点，而不是把所有农场资产机械清零；
- 存活的植物、炮塔、建筑与持久变异跨夜保留，被摧毁后才产生损失；
- 肉鸽卡牌和短期天气在阶段结束后重置，长期天气和灾害可持续数日；
- 敌人从地图边缘、道路、农田、地下和空中进入，而不是固定五条直线；
- 单机家园、合作街区和自由对抗共享同一套长期成长档案，但使用明确的资源边界和反复制规则。

## 当前最重要的设计问题

1. 玩家角色采用固定人物、自定义人物，还是多个可更换身体/职业？
2. 鼠标跟随移动怎样与WASD、战略镜头和点击交互并存？
3. 自动攻击如何做到足够简便，又允许玩家改变目标优先级？
4. 大型无人农机的远方探索采用实时、派遣还是混合方式？
5. 持久植物变异如何通过维护、稳定度和敌人反制保持长期平衡？
6. “火种计划”的技术来源、复活代价和设施失效规则如何设定？
7. 单机与联机随时切换时，资源、建筑和战斗力怎样迁移而不被复制利用？
8. 自由对抗模式怎样既有掠夺刺激，又不摧毁玩家长期投入？

## 推荐的第一阶段原型

只做一张小型美国农场地图，验证以下内容：

- 一栋农舍、一个谷仓、一个牛棚和四块可种植农田；
- 360°敌人来袭与动态寻路；
- 8种植物、3种僵尸、1种飞碟和1种虫族；
- 猫/狗自动拾取资源；
- 白天建设、夜晚防守、三夜后首领战；
- 植物、炮塔和农场战损跨夜保留；
- 一个自由移动、自动攻击、可死亡和复活的玩家角色；
- 一种可下达区域命令的无人农机；
- 单人和两人合作；
- 完整3D场景与斜俯视策略镜头。

在这一原型完成前，不建议同时开发大世界PvP、无限离线收益、复杂载具远征和大规模基地战争。
