> 一个以美国农场为舞台、支持持续建设、360°防御、肉鸽成长、合作街区与开放对抗的长期型塔防/RTS游戏构想。

## 当前核心定位

本作不是把传统《植物大战僵尸》简单改成四面出怪，而是构建一个完整的“**持久农场世界 + 360°肉鸽塔防 + 轻度RTS + 合作/对抗联机**”体系。

建议的技术与视觉方向：

- 底层采用完整3D场景；
- 主视角采用可旋转、可缩放的斜俯视策略镜头，获得2.5D式清晰度；
- 农场可持续扩建，战斗通过昼夜、天气、季节、灾变和远征形成阶段性节奏；
- 敌人从地图边缘、道路、农田、地下和空中进入，而不是固定五条直线；
- 单机家园、合作街区和自由对抗共享同一套长期成长档案，但使用明确的资源边界和反复制规则。

## 当前最重要的设计问题

1. 世界究竟以“美国中西部农场”“大平原农场”还是多地区生物群系为核心？
2. 长期家园和每局肉鸽体验如何分层，避免一局无限拖长？
3. 单机与联机随时切换时，资源、建筑和战斗力怎样迁移而不被复制利用？
4. 自由对抗模式怎样既有掠夺刺激，又不摧毁玩家长期投入？
5. 离线保护怎样兼顾公平、服务器成本和付费边界？
6. 首个可玩原型应只验证哪些机制？

## 推荐的第一阶段原型

只做一张小型美国农场地图，验证以下内容：

- 一栋农舍、一个谷仓、一个牛棚和四块可种植农田；
- 360°敌人来袭与动态寻路；
- 8种植物、3种僵尸、1种飞碟和1种虫族；
- 猫/狗自动拾取资源；
- 白天建设、夜晚防守、三夜后首领战；
- 单人和两人合作；
- 完整3D场景与斜俯视策略镜头。

在这一原型完成前，不建议同时开发大世界PvP、无限离线收益、复杂载具远征和大规模基地战争。
